# 🦖 Dino Dash

Dino Dash is a 2D game developed using C# and Windows Forms in Visual Studio 2022.

## 🎮 About the Game

The player controls a dinosaur and must avoid obstacles while achieving the highest possible score.

## ✨ Features

- Player movement and controls
- Obstacle spawning
- Collision detection
- Score tracking
- Game over system
- Restart functionality

## 🛠️ Technologies Used

- C#
- Windows Forms
- .NET
- Visual Studio 2022

## 🚀 How to Run

1. Clone or download this repository
2. Open the `DinoDash.sln` file in Visual Studio 2022
3. Build the solution
4. Run the game
